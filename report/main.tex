\section{Summary}
This project implements the loop closure detection method proposed by Klopschitz et al. in \cite{Klop}. Our method processes images extracted from video sequences to detect overlaps between camera trajectories. Such techniques are useful in simultaneous localization and mapping (SLAM) applied in mobile robotics or autonomous driving, where we need to detect revisited places for building maps and ensuring navigation accuracy.

    \item extracting optimal alignment paths using a Generalized Scanline Optimization algorithm.

\subsection{Algorithm}
The \textbf{Visual Similarity Matrix (VSM)} is constructed based on the extracted features and each entry $VSM(x,d)$ represents the similarity between image $x$ of the first sequence and image $d$ of the second. For the optimization step, this is converted into a dissimilarity matrix $D = -VSM$.

Once the dissimilarity matrix is obtained, one can apply \textbf{Scanline Optimization} to find the optimal path of correspondence between the two sequences. The algorithm constructs a cost matrix $H$ where $H(x,d)$ represents the minimum accumulated cost of an alignment path ending at $(x,d)$. The relation is defined as:

\begin{equation}
    H(x,d) = \min(0, D(x,d) + h(x,d))
\end{equation}

where $D(x,d)$ is the dissimilarity cost of the current image pair, and $h(x,d)$ represents the minimum cost from the previous row (best previous path), calculated as:

\begin{equation}
    h(x,d) = \min_{d'} \left( H(x-1, d') + \lambda V(d, d') \right)
\end{equation}

Here, $\lambda$ is a regularization weight, $d'$ is an image in sequence 2 for the previous step (the column in the previous row) and $V(d, d')$ is the transition cost, defined to favor diagonal movement (cost being zero in this case):

\begin{equation}
    V(d, d') = \min(|(d+1) - d'|, |(d-1) - d'|)
\end{equation}

Using $\min(0, \dots)$ in Eq. (1) we reset the accumulated cost if the path becomes bad.

Once the matrix $H$ is filled, the optimal loop closure is detected by finding the minimum value in the entire matrix (representing the best ending of a path) through backtracking.
