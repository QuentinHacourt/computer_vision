## How to run?

To run our code, go to the root of our project and execute the following command:

``` shell
./code/run.sh
```

This will set up a virtual environment the first time you run it. If you want to make sure a new virtual environment is created, run the following command:


``` shell
./code/run.sh -i
```

This will set up a new virtual environment no matter if you already created one before.
